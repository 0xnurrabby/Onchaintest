## ✦ Features

<div align="center">

| | Feature | What it does |
|:---:|---|---|
| 🕯️ | Digital candle | Tap once to light the candle and start your focus session |
| 🔢 | Numberless timer | No countdown clock .... just the candle melting at its own pace |
| 😌 | Calm design | Minimal, distraction-free interface |
| 📱 | Farcaster native | Runs inside Warpcast / Base app as a mini app |

</div>

## ✦ Download & Run

**Step 1** .... Clone the repo

```bash
git clone https://github.com/0xnurrabby/Onchaintest
cd Onchaintest
```

**Step 2** .... Serve the public folder

```bash
cd public
start index.html

# Or use a local server
npx serve public
# Open http://localhost:3000
```

**Step 3** .... Tap to light the candle

---

## ✦ Setup

```
1. Clone the repo
2. Navigate to the public/ folder
3. Open index.html in a browser
4. Tap anywhere to light the candle
5. For Farcaster: deploy to Vercel
   Vercel serves the public/ folder directly
   Open inside Warpcast or Base app for the full mini app experience
```

---

## ✦ Project Structure

```
Onchaintest/
  public/
    index.html    ->  entry point with Farcaster mini app meta
    script.js     ->  candle animation and focus timer logic
    Melt-ui.js    ->  UI components for the candle
    assets/       ->  icons, splash, embed images
    .well-known/  ->  Farcaster app manifest
```
